## 📦 Installation

### Prerequisites
- Node.js 18+
- MongoDB (local or Atlas)
- Git

### Setup

```bash
# Clone repository
git clone https://github.com/sakthivelmdesignsbtt-source/sculptor-cad-services-elite.git
cd sculptor-cad-services-elite

# Install dependencies
npm install

# Create .env file
cp .env.example .env

# Update .env with your credentials
nano .env

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
